# Deliberate naming differences between Fusion's command names (fusion-menus.txt) and
# SciForge's menu labels, read by tools/sciforge/parity.py.
#
#   Fusion name = SciForge name
#   Fusion name = SciForge name | another SciForge name      (the first one found counts)
#   AREA > Panel > Fusion name = SciForge name               (only for that place: the left
#                                                             side is the end of the path)
#
# Case, spaces round "/" and a trailing "..." do not matter. Only map a name when SciForge's
# entry really is that command (an honest checklist beats a high number); a unit test checks
# that every line here still matches a Fusion name and a SciForge label.
