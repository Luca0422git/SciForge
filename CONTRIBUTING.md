# Contributing to SciForge

SciForge is a beta and one person directs it, so the process is simple:

- **Found a bug?** Open an issue with the "Bug report" form (or use *Help > Report a Problem* in SciForge, which
  fills the form for you).
- **Have an idea or a question?** Use GitHub Discussions.
- **Want to change code?** Please open an issue or discussion first. Work happens on the `develop` branch; read
  [docs/sciforge/README.md](docs/sciforge/README.md) for how the project is laid out and tested.
- New SciForge code goes in `src/Mod/SciForge/`. Changes to FreeCAD's own files need a `SCIFORGE:` comment and a
  row in [docs/sciforge/core-patches.md](docs/sciforge/core-patches.md).

SciForge is licensed LGPL-2.1-or-later, like FreeCAD, and contributions are accepted under that license.
