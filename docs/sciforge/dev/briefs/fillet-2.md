## Your area: Fillet and Chamfer, part 2, branch `sf/fillet-2`

Fillet and Chamfer exist (`fillet*.py`, `chamfer*.py`; read `docs/sciforge/parity/fillet.md` to the end and the fillet session logs). Build what Fusion's FILLET dialog still has and SciForge lacks:
1. **Radius sets**: several rows in one Fillet step (Fusion's "+" in the selection list: each set has its own edges, radius, type and tangent chain), one timeline step, one undo step, each set's handle and value box on the canvas.
2. **Radius Type**: Constant, **Chord Length** (convert to the constant radius that gives that chord on the actual face angle, per edge) and **Variable** (radius points along the edge: start/end radius, add points by clicking on the edge with position 0..1 and their own radius; OCC `BRepFilletAPI_MakeFillet.SetRadius` with parameter/radius pairs or a law; PartDesign::Fillet cannot, so a `PartDesign::FeaturePython` solid step like `surface.py`'s is fine).
3. **Rule Fillet** (Fusion's Rule Fillet command: All Edges or Between Faces/Features of a feature, rounds and/or fillets, "Rule" re-applies after the model changes).
4. **Full Round Fillet** (pick the side face, centre face, other side face: the centre face becomes a full half-round; compute it with OCC (fillet of the two edges with radius = half width, or a cylinder replace)).
5. **Corner type** Rolling Ball / Setback / Chamfer-corner: build what OCC supports; Setback and G2 continuity are kernel limits (report with evidence). Tangent Chain off: try OCC (`BRepFilletAPI_MakeFillet` with `ChFi3d_Rational` / adding single edges of a tangent chain) and report what works.
6. **Chamfer**: check Fusion's chamfer types (Equal Distance, Two Distances, Distance and Angle), Flip, chamfer sets as rows, Corner type; build what is missing.
Scenarios `fillet2_*.py` (8+ paths: two radius sets in one step, chord length on a 90° and a 120° edge (measured), a variable fillet with three radius points, rule fillet of all edges then the model edited → the new edges are rounded, full round of a rib, chamfer distance + angle with flip, edit from the timeline, undo/redo, save/reopen, a refusal with a clear message, a component). Golden models for each new option. Unit tests for the Qt-free maths (chord → radius, variable law). Update `docs/sciforge/parity/fillet.md`.
